## Setup and use


For the repository root, install Node.js and run:

```sh
npm install
npm run start
```

Use Python 3 and a virtual environment. This submission does not include a `requirements.txt`; inspect the imports listed above and install the packages required by the exercise. Use versions compatible with the original source.

Python entry points include [NLPClassifierSpamDetection.py](backend/NLPClassifierSpamDetection.py), [backend.py](backend/backend.py). Review each script's configuration, arguments, and input paths before running it.
